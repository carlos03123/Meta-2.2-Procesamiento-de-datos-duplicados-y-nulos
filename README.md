# Meta 2.2: Procesamiento de datos duplicados y nulos

En esta actividad trabajé con un archivo de ventas en formato CSV. Utilicé Python y la biblioteca pandas para revisar y procesar valores nulos y renglones duplicados.

## Archivos

* `ventas.csv`: contiene los datos de ejemplo.
* Archivo de Python (`.py`): contiene las funciones de la actividad.

## Actividades realizadas

1. Calcular el porcentaje de valores nulos de cada columna.
2. Contar los renglones duplicados.
3. Eliminar columnas según su porcentaje de valores nulos.
4. Sustituir valores nulos usando la media, `bfill` o `ffill`.
5. Eliminar renglones duplicados.

## Para ejecutar el programa

El archivo de Python y `ventas.csv` deben estar en la misma carpeta. Se necesita tener instalados Python y pandas.
